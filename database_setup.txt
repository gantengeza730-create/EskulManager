EskulManager Database Setup
==========================

This project is configured to use Laravel migrations rather than a custom manual SQL schema. The recommended setup is:

1. Create the database in MySQL
2. Run the Laravel migrations
3. Optionally populate the database with a custom seeder after the tables exist

Database settings from .env:
- DB_CONNECTION=mysql
- DB_DATABASE=laravel
- DB_USERNAME=root
- DB_PASSWORD=

Create the database:

CREATE DATABASE laravel CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE laravel;

Then run the app migrations:

php artisan migrate

If you want to run the default seeder command as well:

php artisan db:seed

Important note:
- The current DatabaseSeeder only clears the data in attendance_records, registrations, and ekskuls.
- It does not insert sample extracurricular data.
- The app is meant to be populated through application logic or custom seeders, not by the default DB seeder alone.

Current migration-based schema
------------------------------

users
CREATE TABLE users (
    id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
    name VARCHAR(255) NOT NULL,
    email VARCHAR(255) NOT NULL,
    email_verified_at TIMESTAMP NULL DEFAULT NULL,
    password VARCHAR(255) NOT NULL,
    role ENUM('admin', 'guru', 'siswa') NOT NULL DEFAULT 'siswa',
    avatar_path VARCHAR(255) NULL DEFAULT NULL,
    class_name VARCHAR(255) NULL DEFAULT NULL,
    phone VARCHAR(255) NULL DEFAULT NULL,
    bio TEXT NULL DEFAULT NULL,
    remember_token VARCHAR(100) NULL DEFAULT NULL,
    created_at TIMESTAMP NULL DEFAULT NULL,
    updated_at TIMESTAMP NULL DEFAULT NULL,
    PRIMARY KEY (id),
    UNIQUE KEY users_email_unique (email)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

ekskuls
CREATE TABLE ekskuls (
    id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
    title VARCHAR(255) NOT NULL,
    category VARCHAR(255) NOT NULL,
    coach VARCHAR(255) NOT NULL,
    description TEXT NOT NULL,
    image VARCHAR(255) NOT NULL,
    created_at TIMESTAMP NULL DEFAULT NULL,
    updated_at TIMESTAMP NULL DEFAULT NULL,
    PRIMARY KEY (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

registrations
CREATE TABLE registrations (
    id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
    user_id BIGINT UNSIGNED NOT NULL,
    ekskul_id BIGINT UNSIGNED NOT NULL,
    status ENUM('aktif', 'pending') NOT NULL DEFAULT 'aktif',
    created_at TIMESTAMP NULL DEFAULT NULL,
    updated_at TIMESTAMP NULL DEFAULT NULL,
    PRIMARY KEY (id),
    KEY registrations_user_id_foreign (user_id),
    KEY registrations_ekskul_id_foreign (ekskul_id),
    CONSTRAINT registrations_user_id_foreign FOREIGN KEY (user_id) REFERENCES users (id) ON DELETE CASCADE,
    CONSTRAINT registrations_ekskul_id_foreign FOREIGN KEY (ekskul_id) REFERENCES ekskuls (id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

attendance_records
CREATE TABLE attendance_records (
    id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
    registration_id BIGINT UNSIGNED NOT NULL,
    user_id BIGINT UNSIGNED NOT NULL,
    ekskul_id BIGINT UNSIGNED NOT NULL,
    attendance_date DATE NOT NULL,
    status ENUM('hadir', 'sakit_izin', 'tidak_hadir') NOT NULL,
    proof TEXT NULL DEFAULT NULL,
    created_at TIMESTAMP NULL DEFAULT NULL,
    updated_at TIMESTAMP NULL DEFAULT NULL,
    PRIMARY KEY (id),
    UNIQUE KEY attendance_records_registration_id_attendance_date_unique (registration_id, attendance_date),
    KEY attendance_records_registration_id_foreign (registration_id),
    KEY attendance_records_user_id_foreign (user_id),
    KEY attendance_records_ekskul_id_foreign (ekskul_id),
    CONSTRAINT attendance_records_registration_id_foreign FOREIGN KEY (registration_id) REFERENCES registrations (id) ON DELETE CASCADE,
    CONSTRAINT attendance_records_user_id_foreign FOREIGN KEY (user_id) REFERENCES users (id) ON DELETE CASCADE,
    CONSTRAINT attendance_records_ekskul_id_foreign FOREIGN KEY (ekskul_id) REFERENCES ekskuls (id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

ekskul_evaluations
CREATE TABLE ekskul_evaluations (
    id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
    registration_id BIGINT UNSIGNED NOT NULL,
    user_id BIGINT UNSIGNED NOT NULL,
    ekskul_id BIGINT UNSIGNED NOT NULL,
    score TINYINT UNSIGNED NULL DEFAULT NULL,
    notes TEXT NULL DEFAULT NULL,
    evaluation_date DATE NULL DEFAULT NULL,
    created_at TIMESTAMP NULL DEFAULT NULL,
    updated_at TIMESTAMP NULL DEFAULT NULL,
    PRIMARY KEY (id),
    KEY ekskul_evaluations_registration_id_foreign (registration_id),
    KEY ekskul_evaluations_user_id_foreign (user_id),
    KEY ekskul_evaluations_ekskul_id_foreign (ekskul_id),
    CONSTRAINT ekskul_evaluations_registration_id_foreign FOREIGN KEY (registration_id) REFERENCES registrations (id) ON DELETE CASCADE,
    CONSTRAINT ekskul_evaluations_user_id_foreign FOREIGN KEY (user_id) REFERENCES users (id) ON DELETE CASCADE,
    CONSTRAINT ekskul_evaluations_ekskul_id_foreign FOREIGN KEY (ekskul_id) REFERENCES ekskuls (id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

extracurriculars
CREATE TABLE extracurriculars (
    id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
    nama VARCHAR(255) NOT NULL,
    kategori VARCHAR(255) NOT NULL,
    created_at TIMESTAMP NULL DEFAULT NULL,
    updated_at TIMESTAMP NULL DEFAULT NULL,
    PRIMARY KEY (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

Notes:
- This project uses MySQL by default.
- The .env file is configured for the database name laravel.
- The role field accepts: admin, guru, siswa.
- The registrations table links users to ekskuls with status values: aktif or pending.
- The attendance_records table uses attendance_date plus status values: hadir, sakit_izin, tidak_hadir.
- The old SQL dump with seed data is no longer the canonical source of truth; Laravel migrations are.

Useful commands:
php artisan migrate
php artisan migrate:fresh
php artisan migrate:fresh --seed
